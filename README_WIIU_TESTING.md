# Ship of Harkinian 9.2.3 for Wii U (experimental)

This is a forward-port of the Wii U backend to Ship of Harkinian 9.2.3. It is an experimental build, not an official Harbour Masters release. It has booted and run through initial gameplay on real Wii U hardware under Aroma; broader compatibility and long-session testing remain in progress.

This guide covers a first installation of Ship of Harkinian as well as an isolated installation alongside the old 8.0.6 Wii U release.

## Important safety information

- Ship of Harkinian itself runs from the SD card. Do **not** put these files in `sd:/install/`, and do **not** use WUP Installer GX2. This is not an installable Wii U title.
- The experimental build deliberately uses `sd:/wiiu/apps/soh-9-2-wiiu/` for its configuration and save files. It does not intentionally write to Wii U NAND.
- Enabling homebrew on a stock Wii U is a separate operation which is not risk-free and may change system storage. Follow the current [Wii U Hacks Guide](https://wiiu.hacks.guide/) exactly, keep the console plugged in, and make the NAND backup when instructed. Do not substitute an old video guide.
- Keep the old `sd:/wiiu/apps/soh/` directory if you already have the stable 8.0.6 port. Do not rename this experimental directory to `soh` or overwrite the stable directory.

## What you need

- A Wii U which can run SD-card homebrew using either:
  - **Aroma**, the current and recommended environment; or
  - **Tiramisu**, the legacy environment, using its Homebrew Launcher.
- An SD card formatted as FAT32. The current Wii U Hacks Guide recommends a 32 KiB (32768-byte) allocation unit and warns not to label the card `wiiu`.
- A Windows, Linux, or macOS computer.
- A supported ROM dumped from a legally owned copy of Ocarina of Time. This repository and its build artifact do not contain Nintendo game assets.

If the Wii U is still stock, complete the [Wii U Hacks Guide from stock to Aroma](https://wiiu.hacks.guide/) before continuing. If Tiramisu is already working, you do not need to migrate to Aroma just to test this build.

## 1. Download the experimental Wii U build

1. Sign in to GitHub and open the [Wii U PR-candidate build runs](https://github.com/doctorjelly/Shipwright/actions/workflows/generate-builds.yml?query=branch%3Awiiu-9.2.3-upstream-pr).
2. Open the newest successful run and download the artifact named `soh-wiiu-9.2.3-experimental`.
3. Extract the downloaded ZIP to the computer. Do not run it from inside the ZIP.

The extracted package contains a directory named `soh-9-2-wiiu`. Leave its three included files together.

- `soh.o2r` - open-source Ship assets generated by the build
- `soh.rpx` - launcher for Tiramisu/Homebrew Launcher
- `soh.wuhb` - launcher for Aroma's Wii U Menu integration

## 2. Generate the legally required game archive

The Wii U cannot generate the game archive itself. Generate it once on the computer:

1. Verify that your legally dumped ROM is supported at [ship.equipment](https://ship.equipment/). The official project also provides a [ROM dumping guide](https://www.shipofharkinian.com/setup-guide/dump-guide).
2. Download the official [Ship of Harkinian 9.2.3 desktop release](https://github.com/HarbourMasters/Shipwright/releases/tag/9.2.3) for Windows, Linux, or macOS.
3. Follow the official [desktop setup guide](https://www.shipofharkinian.com/setup-guide) and select the supported ROM when prompted. Allow the desktop build to finish processing it.
4. Locate the generated `oot.o2r` or `oot-mq.o2r`:
   - Windows and Linux: normally beside `soh.exe` or `soh.appimage`.
   - macOS: `~/Library/Application Support/com.shipofharkinian.soh/`.

Use a `.o2r` generated by a 9.2.x desktop build, preferably exactly 9.2.3. The old official Wii U guide describes 8.0.6 `.otr` files; those are not the correct assets for this port. Do not rename an old `.otr` file to `.o2r`.

## 3. Copy the files to the SD card

1. Power the Wii U completely off before removing its SD card.
2. Insert the SD card into the computer.
3. Copy the extracted `soh-9-2-wiiu` directory into `sd:/wiiu/apps/`.
4. Copy `oot.o2r`, `oot-mq.o2r`, or both into the new `sd:/wiiu/apps/soh-9-2-wiiu/` directory.
5. Confirm this layout, then eject the SD card safely:

```text
sd:/
└── wiiu/
    └── apps/
        └── soh-9-2-wiiu/
            ├── oot.o2r       # required for the original quest, if used
            ├── oot-mq.o2r    # required for Master Quest, if used
            ├── soh.o2r       # included in the build artifact
            ├── soh.rpx       # Tiramisu launcher
            └── soh.wuhb      # Aroma launcher
```

At least one of `oot.o2r` and `oot-mq.o2r` is required. Keep the directory name exactly `soh-9-2-wiiu`.

## 4. Launch it

### Aroma

1. Boot the Wii U into Aroma.
2. On the Wii U Menu, open `Ship of Harkinian 9.2.3 (Experimental)`. Aroma's `homebrew_on_menu` plugin launches `soh.wuhb` directly; the old Homebrew Launcher is not used under Aroma.

If the title is absent, confirm that `homebrew_on_menu.wps` is enabled in Aroma and that `soh.wuhb` is at the exact path shown above.

### Tiramisu

1. Boot the Wii U into Tiramisu.
2. Open the Homebrew Launcher. In a normal Tiramisu setup which autoboots the Wii U Menu, launch Mii Maker to enter it.
3. Select the `soh-9-2-wiiu` application. The Homebrew Launcher uses `soh.rpx`; it ignores the Aroma-only `.wuhb` file.

The Tiramisu route is included for existing installations, but Tiramisu is archived and no longer the recommended environment. Launcher behavior on real hardware remains part of this port's test scope.

## First test sequence

Use the Release artifact linked above. For the first run, do not copy in a save or configuration from another SoH version. Test in this order:

1. Confirm the title says `Ship of Harkinian 9.2.3 (Experimental)`.
2. Reach the file-select screen without copying an old save into the experimental directory.
3. Create a temporary save, enter Kokiri Forest, pause, and save normally.
4. Return to the Wii U Menu using the HOME button, then relaunch and verify the temporary save.
5. Test the GamePad, one external controller if available, audio, suspend/resume, and a normal software shutdown.

If the console freezes, wait briefly and try HOME before holding POWER as a last resort. Stop testing after any repeatable crash or sign of save corruption.

## Uninstall or roll back

Power the console off, remove the SD card, and delete only `sd:/wiiu/apps/soh-9-2-wiiu/`. This removes the experimental executable, its assets, its configuration, and its saves. It does not remove or change an installation in `sd:/wiiu/apps/soh/`.

## Troubleshooting

- **The application is not listed:** verify the exact directory layout and use the launcher for your environment: `.wuhb` on Aroma or `.rpx` through Tiramisu's Homebrew Launcher.
- **The game reports missing or incompatible assets:** regenerate `oot.o2r` or `oot-mq.o2r` with the official 9.2.3 desktop release; do not use the old 8.0.6 `.otr` archive.
- **It returns to the menu, freezes, or crashes:** remove the experimental directory if necessary and report the build commit, Wii U firmware region/version, Aroma or Tiramisu version, controller setup, and the last visible screen or error.
- **A GitHub artifact link has expired:** open the branch's [generate-builds runs](https://github.com/doctorjelly/Shipwright/actions/workflows/generate-builds.yml?query=branch%3Awiiu-9.2.3-bringup) and use the newest completed successful build of the Wii U code.

## Known validation boundary

The Aroma build has been verified on real hardware through launch, file selection, saving and relaunching, GamePad input, audio, and initial gameplay. Tiramisu, suspend/resume, external controllers, and long-session stability still need broader testing.
